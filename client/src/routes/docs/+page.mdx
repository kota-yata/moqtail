# Moqtail Documentation

Welcome to the Moqtail docs. These pages are written in MDX (via mdsvex), so you can mix Markdown with Svelte components.

## Quick Start

Install and import the components you need, then wire them into your Svelte app.

```svelte
<script lang="ts">
  import MoQTSubscriber from '$lib/components/MoQTSubscriber.svelte';
  import MoQTPublisher from '$lib/components/MoQTPublisher.svelte';

  let moqtServerUrl = 'https://example.com/moq';
</script>

<MoQTPublisher {moqtServerUrl} />
<MoQTSubscriber {moqtServerUrl} videoWidth={640} videoHeight={360} />
```
